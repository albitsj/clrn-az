## 后续基准与失败处理规则

README 中“容差内恢复旧图”的叙述仅保留为历史操作记录，不是今后更新的硬性
规则。确认的预期应用更新优先逐图更新唯一当前基准；不为了保留旧图引入重遮罩、
扩大遮罩、增大容差、增加重试或同时接受旧新布局。无意义波动也不批量替换。

失败先核对当前测试提交、部署 Release/完整应用 SHA、设备环境和网络夹具，
读取同轮完整日志、实际/预期/差异图及适用录像。应用缺陷保留失败，环境问题
先修复环境，测试缺陷修复采集或断言；原因不明不接受图片。预期变化走固定 CI
reference，逐张审阅该轮实际成功采集的候选图，再提交当前主基准并执行完整
compare。reference 或 `--list` 成功都不能当回归通过。缺少证据时保留未通过，
不要自动批准动画“无变化”。
